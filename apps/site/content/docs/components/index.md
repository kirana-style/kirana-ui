# Components

Each page shows the component live, how to install it with either CLI, how to use it on
each base, and the code installing it writes. Choose the framework and base above a
preview: every page follows the choice. React has every component, on Base UI and React
Aria; Vue has seven on Ark UI (Button, Card, Dialog, Dropdown Menu, Select, Skeleton and
Tabs); Svelte and Solid (on Ark UI) and Angular (on ng-primitives) have Button, Card and
Skeleton so far.

| Component                                       | What it is                                                                                    |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------- |
| [Avatar](/docs/components/avatar)               | An image element with a fallback for representing the user.                                   |
| [Breadcrumb](/docs/components/breadcrumb)       | Displays the path to the current resource using a hierarchy of links.                         |
| [Button](/docs/components/button)               | Displays a button or a component that looks like a button.                                    |
| [Card](/docs/components/card)                   | Displays a card with a header, content and footer.                                            |
| [Chart](/docs/components/chart)                 | Charts on TanStack Charts, each series in one of the design's chart colours.                  |
| [Collapsible](/docs/components/collapsible)     | An interactive component which expands and collapses a panel.                                 |
| [Dialog](/docs/components/dialog)               | A window overlaid on the page.                                                                |
| [Dropdown Menu](/docs/components/dropdown-menu) | Displays a menu of actions or functions, triggered by a button.                               |
| [Field](/docs/components/field)                 | Combines a label, a control and help text.                                                    |
| [Input](/docs/components/input)                 | Displays a form input field.                                                                  |
| [Label](/docs/components/label)                 | Renders an accessible label associated with a control.                                        |
| [Select](/docs/components/select)               | Displays a list of options to pick from, triggered by a button.                               |
| [Separator](/docs/components/separator)         | Visually or semantically separates content.                                                   |
| [Sheet](/docs/components/sheet)                 | Extends the Dialog to display content from an edge of the screen.                             |
| [Sidebar](/docs/components/sidebar)             | A composable, themeable and customizable sidebar component.                                   |
| [Skeleton](/docs/components/skeleton)           | Shows a placeholder while content is loading.                                                 |
| [Tabs](/docs/components/tabs)                   | A set of layered sections of content, displayed one at a time.                                |
| [Tooltip](/docs/components/tooltip)             | A popup that displays information related to an element when it receives focus or is hovered. |

More of shadcn/ui's components follow as they are ported.
